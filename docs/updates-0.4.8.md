# 两三事 0.4.8

### 恶魔轮盘：随机开局与轮次交替换先手
- **首轮掷硬币随机先手**：对决开启时（接受邀请或直接开局），系统进行 50% 掷硬币随机决断，由 `<user>` 或角色先手行动；系统播报及开局卡片同步明示先手方，彻底告别单方固定先手的机械感。
- **弹仓打空轮换交替先手**：
  - 当一轮弹药耗尽进入重新装填阶段时，下一轮先手自动交替轮换（奇数轮 1/3/5... 归首轮先手方，偶数轮 2/4/6... 归另一方先手）；
  - 换轮装弹时自动清除上一轮残留的手铐限制，并更新系统播报明示交替后的先手角色。
- **AI 随机先手无缝出招**：掷硬币判定角色先手时，系统在接受对决后直接激活 AI 行动逻辑并自动触发续写出招，无需用户手动多余点击。

### 设置面板与提示词编辑体验优化
- **提示词库与日志回流折叠**：
  - 提示词库卡片默认采用折叠手风琴布局，点击标题即可按需展开编辑，避免数十个提示词同时铺满屏幕；
  - 手机回流日志预览框支持折叠收起，去除多余重复的系统提示词副本，信息呈现更紧凑清晰。
- **编辑视窗大幅扩容**：预设编辑器与提示词卡片文本域高度扩展至更充裕的行高，便于长文提示词编写与审阅。

# 两三事 0.4.10

### 日历工作日/节假日作息与提示词注入系统
- **工作日与节假日由历法自定义决定**：
  - 日历设置新增「工作日与作息」面板，支持用户按星期自由勾选工作日与公休日（支持单休、双休、无休或任意自定义历法周期）；
  - 支持节日重合策略：可选「节日优先覆盖工作日」或「两者重合叠加提示」。
- **提示词细化到 24h 制与分时段/分天设定**：
  - 用户可自由配置工作日与节假日的默认提示词；
  - 支持添加多个 24 小时制精细时段规则（如 09:00 - 18:00、支持跨午夜如 23:00 - 07:00）；
  - 支持按工作日、节假日或特定星期单独指定该时段的专属提示词；
  - 自动从正文或 AI 最新楼层中解析 24h 时间并命中匹配时段。
- **角色卡深度绑定与独立启闭**：
  - 提示词作息配置随角色卡独立保存，切换角色卡自动切换对应作息；
  - 提示词注入支持独立开关，新增系统预设条目与插槽宏 `{{workday_holiday_prompt}}`。

### 日历事件可编辑与保存优化
- **已有事件就地修改与保存**：
  - 非内置的节日、纪念日与待办事件卡片新增编辑（铅笔）按钮；
  - 点击即可打开编辑表单并回填全部事件字段，修改后保存自动持久化；
  - 修改待办事项时，联动同步更新待办清单对应项目的标题与日期。
- **日历设置面板交互升级**：
  - 日历设置改为屏幕居中遮罩浮窗，点击右上角设置图标即刻居中弹出。

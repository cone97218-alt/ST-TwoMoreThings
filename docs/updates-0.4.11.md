# 两三事 0.4.11 更新说明

### 1. 日历「作息设置」入口显著化
- **日历顶部与操作栏直达**：在日历顶部导航新增「作息」快捷按钮，并在下方日期操作栏（「添加」事件旁）增加直达的「作息设置」按钮，一键展开工作日与作息设置面板。
- **默认聚焦作息标签**：打开日历设置弹窗时，直接默认定位在「工作日与作息」选项卡，告别层层寻找。
- **设置页总控开关**：在主设置「内容设置」中同步加入「工作日/作息带入提示词」独立开关。

### 2. 角色卡随卡脚本同步（Bug 修复）
- 修复了卡内手机配置导出与还原（`authoring.js`）时遗漏 `workdayConfig` 的问题。现在随卡导出的角色包能完整保留作者配置的工作日、节假日、24h 时段与专属提示词。
- 升级提示词预设架构版本（Schema v7），确保所有旧存档自动补全工作日/节假日感知提示词条目。

### 3. 日历内置节日编辑与覆盖优化
- 内置节日支持平滑修改与保存，修改后的节日将自动生效并覆盖默认节日显示。

# 两三事 0.4.16 更新说明

### 1. 群聊思维链（Reasoning / CoT）支持
- 群聊消息续写现已支持提取模型的思维链（Reasoning Process / Chain of Thought），并挂载在首条生成的群聊消息上；
- 群聊界面操作条支持直接点击查看思维链弹窗，与私聊体验一致。

### 2. 私聊与群聊社交圈感知独立开关
- 设置面板中为 Ainstagram 动态增加了细分感知控制；
- 可分别独立开启或关闭私聊和群聊对社交圈动态的上下文感知。

### 3. 日历自拟与AI生成节日重复注入修复
- 修复自拟节日或AI构想虚构节日（如春7日花舞节等）在批量保存、日历上下文渲染与正文回流注入中可能重复两次注入的缺陷；
- 完善同名内置节日排除与日历数据防重自愈机制。

### 4. 短信回流正文记忆摘要预设装配修复
- 修复参考文本较长时触发的短信回流正文记忆摘要（`{{summary_prompt}}`）未经过提示词预设引擎装配的问题；
- 摘要生成现已严格遵从提示词可视化中预设条目的启用状态、排序、角色与宏插槽替换。

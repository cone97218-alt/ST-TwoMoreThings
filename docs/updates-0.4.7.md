# 两三事 0.4.7

### 恶魔轮盘：战局提示词精炼与回合判定优化
- **高密度极简战局实况**：将原先冗长的战局档案重构为 5~6 行精炼核心态势（当前第 n 轮、剩余实弹/空弹、双方血量、双方可用道具、特殊状态），彻底消除 Prompt 冗余与 Token 浪费。
- **根治回合混淆**：
  - 彻底淘汰模糊易混淆的“你”、“对方”、“玩家”及人名括号备注，统一采用客观规范的 `【<user>】` 与 `【角色】`；
  - 严格根据底层回合归属动态分流行动指令：当前为角色回合时明确命令出招，当前为 `<user>` 回合时明确禁止代打，彻底消除角色与玩家抢枪或回合认知错位。
- **战局生命周期自动控制**：战局推进实况提示词仅在对决进行中（`playing`）注入，对决分出胜负或终止后立即彻底停止注入，恢复纯净私聊上下文。

### 两阶段对决卡片与终局结算卡
- **去除实时轮次重写**：开局卡片固定注明对决开始与赌注，不再随每轮射击动态篡改历史文本，避免上下文反复突变。
- **终局独立结算卡**：无论是角色扣动扳机分出胜负，还是玩家开火终结对局，系统均会在开火动作后再次输出一张独立的对局结算卡，明示最终胜者（`<user>` 或 `角色`），让战局起止节点清晰完整。

### 终局 Token 自动减负与 5 轮缓冲带
- **终局 5 轮过渡缓冲**：对决结束后，击发与道具过程播报在后续 5 轮 AI 回复内继续保留注入，确保角色与用户能自然顺畅地调侃胜负、商讨兑现赌注；第 6 轮起自动清除历史播报，彻底释放 Token。
- **界面折叠收纳保持解耦**：聊天流中的对战过程依然在终局后第一时间收拢为 `恶魔轮盘对决结束 ▾` 胶囊，随时一键展开复盘。

# 两三事 0.4.27 更新说明

### 1. 随身系统：新增「系统日志」常驻审计模块
- **全历史记录回溯**：在随身系统 APP 顶部导航栏新增「日志」常驻标签页，用户可随时回溯查看历史所有任务派发/完成/失败、属性增减与突破理由、积分结算、物品消耗与商城进货记录；
- **分签筛选与快捷清空**：支持「全部 / 任务 / 属性 / 积分 / 物品 / 评估」快速分类筛选，提供一键清空日志与操作确认保护。

### 2. 正文注入与属性格式重构
- **属性数值格式规范**：修正主聊天正文中的属性注入显示，消除正号（如显示 `智力 3` 而非 `智力加3`），使角色能力面板更自然纯净；
- **属性变动支持理由解析**：回传数据块升级为 `属性|名称|+N或-N|理由`，AI 评估或战斗结算时附带的成长因由自动沉淀记录到系统日志中；
- **任务派发规则去编号化**：`{{taskRule}}` 宏生成的派发规则剥离硬编码数字序号，纯净平铺于规则列表中。

### 3. 提示词管道与功能提示词库深度归位与解耦
- **正文注入与 APP 私聊清晰分治**：彻底剥离随身系统 APP 内的正文注入配置与私聊功能，正文注入卡片严格保留 6 个剧情注入模块（面板、任务、背包、推进、规则、回传）；
- **系统私聊规则进入统一管道**：系统专属私聊规则（`origin_chat`）正式归位至插件主设置的「功能提示词库」（新增【随身系统】分类标签）以及「条目装配管线」（`entry_origin_chat_rules`，作用域：`系统私聊`，插槽宏：`{{origin_chat_prompt}}`）；
- **丰富宏定义支持**：系统私聊模板完全开放自定义，支持 `{{sysName}}`、`{{hostName}}`、`{{persona}}`、`{{level}}`、`{{exp}}`、`{{expMax}}`、`{{points}}`、`{{stats}}`、`{{tasks}}`、`{{bag}}` 等动态宏；
- **消除代码内硬编码提示词**：全面清理代码中各处硬编码的 Fallback 系统提示词与小游戏冗余副本，实现全插件提示词的单一真实数据源。

### 4. 测试与稳定性保障
- 全套 441 项单元与端到端自动化测试 100% 通过。

# 两三事 0.4.0

### 电波聊天与互动交互升级
- **消息气泡互动增强**：新增气泡悬浮/长按动作栏，支持快捷引用、表情回应（Emoji Reactions）、消息撤回与秒撤回、消息重新编辑。
- **角色隐秘心声推演**：支持为任意消息推演发信瞬间角色的真实潜台词，头像带光晕提示，点击即可查看心声。
- **引用消息 UI 优化**：将引用内容移至消息气泡外侧上方，字体更轻更浅，视觉体验更干净自然。
- **多选与转发**：支持消息批量多选、转发至指定联系人并附带留言，新增收藏消息与收藏夹管理。
- **双击头像拍一拍**：在私聊与群聊中双击对方头像可发起轻量拍一拍互动，角色与群友亦会自然回拍与互动。
- **AI 主动交互全面就绪**：角色与群成员可根据情绪语境主动引用历史消息、转发聊天记录、秒撤回欲言又止的句子、贴 emoji 回应气泡等。

### 世界书注入与过滤优化
- **修复世界书注入顺序完全颠倒的问题**：严格对齐 SillyTavern 标准管线，修复此前倒序排布 Bug，支持位置桶先后排序、@深度降序与桶内升序装配。
- **全面对接柏宝书世界书排除体系**：
  - 支持渲染世界书模板（宏展开与 EJS 模板运算）；
  - 支持整本排除世界书（支持搜索筛选与一键勾选，双向实时跨插件同步）；
  - 支持按条目名与正则过滤（预置 MVU 机制条目过滤，支持自定义正则）。

### 提示词库格式重构
- 全拓展 17 个功能提示词统一采用 `[功能名]` 标题与层次分明的 YAML 格式（`- 功能` / `  - 功能介绍` / `  - 功能格式`），显著增强大模型遵循度与稳定性。

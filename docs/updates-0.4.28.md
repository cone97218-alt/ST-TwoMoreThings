# 两三事 0.4.28 更新说明

### 1. 日历与天气系统深度联动
- **锁屏界面全要素气象联动**：告别写死的默认 22°C 与单一太阳图标，锁屏优先联动日历当前的剧情天气与剧情锁定天气；动态根据阴晴雨雪渲染雨天、雪天、云雾、雷暴等对应的动态矢量 SVG 图标；支持现代气温数字与古代物候辞藻。
- **主界面桌面小日历组件展示天气**：桌面（主屏）正中央的小日历卡片中，同步融入自适应天气胶囊角标（包含矢量图标、气象文字、气温与锁定标识），排版精致，完全适配白天与暗夜主题。
- **气象推演基准与来源透明化**：在日历设置界面的天气 Tab 中增加明确的推演基准提示，清晰呈现当前推演所依据的地点名称以及推演机制。

### 2. 移动端触屏适配与「环境气象详情」弹窗
- **轻触弹出气象详情**：解决手机触屏无法悬停（hover）查看天气来源依据的痛点；日历顶部天气角标升级为具备触控反馈的按钮，轻触即可唤起专门为移动端设计的「环境气象详情」弹窗。
- **全方位气象与地点解析明细**：弹窗内集中呈现当前气温、历法时代、识别地点、地点解析来源（如剧情顶部时间栏、正文标注、柏宝书、默认城市等）、推演机制以及当前注入给 AI 角色的剧情环境提示词预览。
- **无缝操作与全端协同**：弹窗内置「天气设置」一键跳转按钮与关闭按钮，并支持点击背景遮罩关闭与 Esc 快捷键；主界面小日历上的天气胶囊轻触亦可直接展开该详情弹窗。

### 3. 系统稳定性与全局容错增强
- **修复无桥接环境下的加载异常**：补全 `qqjBridgeProvider` 的安全降级与函数类型检查，彻底解决无桥接插件时打开手机可能引发的空白屏问题。
- **全局渲染错误边界（Error Boundary）**：核心主循环增加自动捕获与自愈机制，即使发生极端渲染异常也会优雅展示错误提示与重置到主页按钮，杜绝死寂白屏。

### 4. 自动化测试验证
- 全套核心单元测试 100% 通过，覆盖天气联动、移动端弹窗与桌面小部件交互。

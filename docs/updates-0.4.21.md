# 两三事 0.4.21 更新说明

### 1. 全新「随身系统」金手指功能上线
- **手机 App 与独立应用**：手机主屏新增「系统」App，支持查看宿主当前等级、经验值、系统积分、数值属性、进行中任务、背包物品、万象商城与祈愿抽奖。
- **系统专属私聊**：激活后自动在手机短信中建立随身系统专属私聊窗口，支持直接与系统对话、咨询进度、交互剧情或请求任务。
- **三种任务演进机制（路线 A / B / C 并行）**：
  - **路线 A（系统私聊）**：直接在短信中向系统沟通，系统按预设性格回复并下发结构化任务卡片；
  - **路线 B（应用内主动推演）**：在系统 App 任务页与属性页中，点击 AI 推演按钮，AI 结合当前正文剧情与宿主期望方向批量构想新任务或评估角色属性成长；
  - **路线 C（正文自然/标签侦听）**：根据正文输出自动捕获任务发布、完成、属性变动、背包道具与成就解锁，支持自定义自然正则（如 `【叮！...】`）与自定义 XML 结构化标签正则（如 `<origin>`、`<系统>`）。
- **提示词可视化与预设管道打通**：
  - 提示词管道新增「系统」生效范围与对应宏插槽（`{{origin_prompt}}`、`{{origin_chat_prompt}}`、`{{origin_task_conceive_prompt}}`、`{{origin_stats_eval_prompt}}`、`{{origin_shop_conceive_prompt}}`、`{{origin_gacha_conceive_prompt}}`）；
  - 系统所有操作均与提示词日志完美打通，清晰展示装配流与推演记录。

### 2. 界面与交互体验全面重构
- **纯图标按钮与轻量风格**：
  - 任务、属性、商城、祈愿页顶部操作栏全部简化为纯图标按钮（`+`、`✨`、`🎯`、`🔄`、`🗂`），带原生悬停说明；
  - 彻底清理多余厚重背景色与粗边框，与手机整体手账拟物风格完全统一。
- **私聊任务卡片美化**：
  - 短信对话中的任务卡片重构为专属视觉样式，目标条件与具体内容分行展示；
  - 奖励行与时限/跳转行分行独立排列，杜绝字词竖排挤压；
  - 点击任务卡片可直接一键跳转至系统 App 对应任务。
- **滚动位置精准记忆**：
  - 无论任务结算、删除、属性微调、商城换批还是弹窗保存，系统界面严格保持在原有滚动位置，不再跳回顶部。
- **倒计时回合逻辑与非修真中性库**：
  - 修复时限回合数解析与倒计时显示 bug；
  - 惩罚文本去除红色警示特殊标记，融入常规界面调色；
  - 商城与祈愿默认库彻底去修真化，全面采用中性、通用、现代都市与情感剧情适用的道具体系。

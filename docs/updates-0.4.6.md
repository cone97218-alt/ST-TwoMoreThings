# 两三事 0.4.6

### 新增对战小游戏：恶魔轮盘 (Buckshot Roulette)
- **生死轮盘博弈**：霰弹枪装填随机打乱的实弹与空弹，支持朝对方开枪或朝自己扣动扳机（空弹保留回合获得额外出招机会），胜者掌握赌注主动权！
- **战术道具系统**：双方每轮随机分配五款策略道具，全套单色线性矢量图标无缝融入插件原生风格：
  - 🔍 **放大镜**：暗中窥视枪膛内第一发子弹虚实；
  - 🪚 **手锯**：切断霰弹枪枪管，下一发实弹致命伤害翻倍为 2 点；
  - 🍺 **啤酒**：退出膛内当前第一发子弹并当场向全场揭晓；
  - ⛓️ **手铐**：锁住对手，强制其跳过下一个行动回合；
  - 🚬 **香烟**：平复紧张心绪，立即恢复 1 点生命值。
- **规则图鉴与战局档案**：
  - 对决桌顶栏手柄按钮支持一键呼出抽屉，自由切换「规则图鉴」与「战局档案」；
  - 战局客观档案按轮次清晰记录初始弹药配比、实际打出数量与关键动作，彻底避免 AI 混淆轮次。

### 对弈提示词与表现双轨机制
- **纯私聊台词规范**：角色消息正文（`messages[].text`）严格遵循纯手机私聊台词规范，严禁出现括号小说式动作旁白，通过真实打字用词、标点与情绪反应展现生死博弈的紧张感与挑衅。
- **权威系统裁决播报**：角色动作描摹与底层系统裁决（实弹/空弹、伤害、剩余生命值、换弹与道具生效）无缝融合，二者兼备。
- **防卡死保底与快捷催促**：AI 决策算法全面支持连续道具连击与空弹追击，内置完整扳机收尾保底；同时在面板状态栏提供「催促开枪」按键，随时一键唤醒对弈推进。

### 终局 Token 自动减负与战况折叠收纳
- **模型上下文终局过滤**：对决结束后，系统自动从发送给大模型的 Prompt 历史中剔除中间大量琐碎的击发与道具播报，仅保留终局总结卡片与双方文字聊天，瞬间节省上千 Token 宝贵上下文，彻底避免干扰后续日常剧情。
- **界面战况一键收拢**：对局结束后，聊天流中原先占屏的连续播报条默认自动收敛为一条精致轻盈的 `恶魔轮盘对决结束 ▾` 胶囊，点击即可随心展开复盘历史细节，清爽不刷屏。
- **UI 视觉优化**：系统播报胶囊宽度自适应铺满聊天流，彻底消除两侧多余内缩空白与末尾单字突兀折行。

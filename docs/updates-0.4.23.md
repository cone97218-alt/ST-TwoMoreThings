# 两三事 0.4.23 更新说明

### 1. 修复 AI 地图弹窗无法打开的严重问题
- 修复了在地图界面点击 AI 整理/校准按钮时，因底层变量缺失抛出 `ReferenceError` 导致弹窗无法弹出的 bug。

### 2. 人物在场卡片全屏自适应与防截断重构
- **解绑图钉容器限制**：将浮动卡片移出局部图钉容器，直接挂载到全幅地图图层，脱离图钉文本宽度的干扰，获得完整的可视视窗参照系；
- **全方位绝对安全边界约束**：
  - 水平方向采用动态视窗边界锚定（`max(8px, ...)`），无论图钉处于最左还是最右边缘，卡片严格留有安全内边距，永不向侧方溢出；
  - 垂直方向根据图钉所在半区自适应贴合（上半区向下展开、下半区向上展开），并设置视窗高度硬性保护限制（`max-height`），顶部与底部绝不被地图画框截断；
- **排版与交互体验优化**：
  - 卡片内部列表启用平滑纵向滚动，人物关系说明文字支持自然换行与自适应折行，不再撑爆卡片宽度；
  - 卡片右上角新增便捷关闭按钮（`×`），并支持随时点击图钉快速收起。

# 两三事 0.4.12 更新说明

### 1. 工作日与节假日作息支持「带入正文主模型」
- **主模型与副 API 协同**：
  - **手机副 API**（私聊/群聊/推文）：通过预设宏 `{{workday_holiday_prompt}}` 注入角色作息提示词。
  - **正文主模型**（酒馆主楼对话/剧情）：新增「带入正文主模型」独立开关。开启后，插件回流服务（Backflow）在主模型生成正文时自动注入 `[当前作息：...]`，使主模型能根据剧情时间与 24h 时段精准掌握角色的忙闲状态与生活作息。

### 2. 移动端 UI 极简排版与紧凑优化
- **7 联单字胶囊工作日切换器**：
  - 彻底摒弃旧版带有断行问题的复选框，采用紧凑的 `[一] [二] [三] [四] [五] [六] [日]` 7 联等宽胶囊按钮，一行完整排列，彻底杜绝手机端汉字垂直折行（如“周\n一”）。
  - 点按即时高亮切换，视觉精致统一。
- **开关与文本长句简化**：
  - 简化文字描述与占位符，消除移动端标题与多选框被挤压换行的尴尬。
  - 24h 时段规则卡片与“+ 添加时段”按钮单行对齐，结构更加紧凑利落。
- **日历事件支持修改与保存**：
  - 日历事件列表中新增编辑（铅笔）按钮，支持原地编辑修改节日、纪念日与待办事件，修改后的待办事项会自动联动更新待办清单。

# 两三事 0.4.18 更新说明

### 1. 跨天日历与待办事项注入提示词优化
- **跨天总天数与当前进度标注**：
  - 当节日、纪念日或待办事项持续多天（跨天）时，在注入的提示词与日历线索中自动注明**总天数**与**当前为第几天**（如 `进行中（共3天，当前为第2天）`）；
  - 未来即将到来的跨天事项会自动标注持续总天数（如 `3天后（共5天）`），单日事项保持原有简洁格式。
- **跨天待办事项（Todo）联动支持**：
  - 支持从待办事项的持续天数（`days`）、起止日期（`startAt` / `endAt`）或日期区间文本中解析跨天跨度与当前所处天数；
  - 严格遵循待办隐私边界，仅向知情参与者注入相关私密跨天待办。
- **全链路提示词覆盖**：
  - 同步优化提示词预设 `{{calendar_prompt}}` 插槽、手机内部上下文 `{{phone_context}}` 以及正文回流 `[日历线索]` 与 `[用户保留的事项]`，引导 AI 自然体现跨天事件首日开启、中途进行或尾声收官的节奏。

# 两三事 0.4.26 更新说明

### 1. 提示词装配管线：删除条目增加二次确认保护
- **防止误触删除**：在装配管线卡片标题栏点击「×」按钮，或在展开抽屉点击「删除条目」时，系统会弹出明确的二次确认对话框（`确定要从当前装配管线中删除条目「xxx」吗？`），避免误触导致精心编写的规则丢失；
- **抽屉底部新增删除按钮**：在条目展开抽屉的底部左侧新增专门的危险操作「删除条目」按钮，与右侧的排序按钮分居两侧，操作路径更清晰；
- **即时交互反馈**：确认删除后弹出操作反馈提示，并自动关闭对应已折叠的抽屉。

### 2. 天气与位置感知联动增强
- **顶部时间地点栏感知**：增强对主聊天顶部格式栏（`✧时间|地点|天气✧`）中移动目的地（`出发地 → 目的地`）的提取解析；
- **柏宝书位置双向互通**：支持从柏宝书（ST-BaiBai-Book）的最新剧情节点直接提取当前所在地点，自动与天气模块无缝衔接。

### 3. 测试与稳定性保障
- 全套 438 项单元与端到端自动化测试 100% 通过。

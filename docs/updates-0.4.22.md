# 两三事 0.4.22 更新说明

### 1. 百宝书（STBaiBaiBook）地图空间方位与层级校准
- **相对方位与层级推演**：
  - 新增 AI 百宝书地图校准服务，针对百宝书已有地点推演空间相对方位（东西南北中、内外）与三层语义层级（分区 Area / 场所 Site / 室内 Interior）；
  - **白名单严格安全约束**：校准模式严格锁定已有场景，严禁 AI 擅自新增或篡改地点名称。
- **元数据适配层（baibaiOverrides）**：
  - 采用无侵入覆盖层存储校准属性，无需修改外部百宝书数据源即可即时生效；
  - 布局引擎支持东/西/南/北/中方位亲和映射（Quadrant Affinity Layout），彻底解决百宝书场景散乱错位问题。
- **撤回与重置安全机制**：
  - 地图头部新增撤回操作，AI 构想或校准后可随时一键回退到变动前快照；
  - 设置中支持地图完全重置，并具备防误触撤回恢复能力。

### 2. 提示词预设与插槽宏管道打通
- **宏隔离与提示词组支持**：
  - 注册 `map_calibrate` 独立功能提示词与 `{{map_calibrate_prompt}}` 预设宏；
  - 提示词管道隔离：在校准模式下互斥屏蔽旧构想宏，杜绝旧版构想指令意外污染；
  - 修复多宏混合条目过滤 bug，预设架构版本升级至 v9。

### 3. 地图 UI 与微交互体验优化
- **分段胶囊 Tab 重构**：
  - AI 弹窗 Tab 全面重构为现代拟物分段胶囊控制器（Segmented Pill），带状态浮动阴影与矢量图标（✨ 构想新地点 / 📍 校准已有地点）；
  - 消除标题栏冗余的外边距累加，大幅紧凑弹窗顶部视觉呼吸间距。
- **边缘图钉人物卡片防截断**：
  - 解决角色处于地图四周边缘或角落时人物在场浮窗卡片被画布截断的 bug；
  - 新增自适应方位算法：靠左靠右自动水平停靠（`.align-left` / `.align-right`），靠下边缘自动向上翻转（`.pos-top`），确保在任何极端位置均完整可见。

# 两三事 0.4.17 更新说明

### 1. 短信回流正文记忆摘要双模式（手动挡与自动挡）
- **手动挡模式**：
  - 在短信首页顶部「+」号菜单中新增「总结短信」入口（与整理通讯录、新建联系人、创建群聊并列）；
  - 点击即可主动生成并保存短信记忆摘要，带入正文；正文对话生成时不再自动调用总结 API，避免额外请求。
- **自动挡防重复总结与缓存优化**：
  - 聊天关闭手机返回正文后，在下一次正文 AI 回复前自动调用一次短信总结；
  - 引入基于手机短信与待办变动的内容哈希（Phone Hash）缓存机制。只要手机内部没有产生新消息，后续正文聊天直接复用已生成的摘要，彻底消除每聊一句正文都重复调用一次总结 API 的问题。
- **设置面板支持切换**：
  - 在设置面板中支持随时在「自动挡」与「手动挡」之间自由切换。

### 2. 回流摘要字数容错与可配置上限
- **动态字数宏替换**：将提示词库中的 `maxCharacters` 变量自动替换为具体目标字数，使大模型获得明确的长度要求；
- **超长自动截断**：新增「超长时自动截断」开关（默认开启），当大模型生成的摘要略微超出上限时自动平滑截取，不再报错丢弃；
- **字数上限可调**：新增「摘要字数上限」配置项，支持用户自定义 50~1000 字（默认 100 字）。

### 3. 长线剧情记忆宏 `{{story_memory}}` 摘要装配支持
- 将剧情长线记忆适配器（如柏宝书长线记忆摘要及千千结）接入短信回流摘要生成流；
- 预设中的 `{{story_memory}}` 宏在短信回流摘要生成时能够正常展开并注入提示词。

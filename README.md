# 两三事 · ST-TwoMoreThings

给 SillyTavern / Luker 里的角色一部小手机。

从大数字锁屏进入桌面，打开短信、论坛、动态、日历、待办和设置，让手机里的日常接上当前剧情。

## 手机里有什么

- **私聊与群聊**：整理联系人，也可手动配置人物、群成员、头像、网名和线上聊天习惯。群聊支持成员艾特高亮、点头像插入艾特，以及引用具体消息回复。
- **日常消息**：支持双语短信、Blob 行内小表情与 Blob／Sepia 大贴纸、定位、转账，以及角色发来的图片卡。
- **剧情论坛**：刷新查看当前故事中的帖子与讨论。
- **ainstgram 动态**：手动刷新好友和路人的近况，人物主页可补充历史；留言先发布，回应继续生成，可去其他页面，回复有未读提醒。动态也能成为短信话题或让角色主动联系。刷新首页会替换上一批。
- **锁屏与桌面**：可选启用或关闭锁屏系统（关闭后打开手机直达桌面）；默认、「纵时」与花瓣剪纸「圆时」三种锁屏风格，日夜配色，支持自定义背景、未读通知和指纹按钮进入桌面。
- **手机内推送**：离开对应页面后，短信、评论回复以及论坛或动态生成完成会在手机顶部提醒，点按回到对应内容；短信与评论回复的未读同时保留在锁屏。
- **聊天记录**：资料和消息随当前聊天保存，过去的记录可折叠查看；清屏只清理当前批次。
- **独立日历与事件**：内置独立日历引擎与通用节日，支持在手机日历应用内新增、删除自定义事件并随卡导出；自动结合剧情日期注入进行中和临近节日，无外部依赖。
- **轻量待办**：短信中的明确约定可生成建议卡，确认后加入待办；记录剧情开始、结束时间和相关人，未完成项显示桌面角标。完成需手动勾选，剧情进展不会自动同步。
- **手机信息参考**：私聊保留近期记录，群聊可按成员知情范围参考私聊约定，动态也可成为话题。开启短信带入正文后，当前短信与已确认待办作为参考，由主楼本次生成结合已有剧情决定如何采用；短材料不增加请求，超过3000字符才沿用一次摘要，同时核对进展，不另加分析调用。

## 插件联动

日历内置独立引擎与节日计算，也可自动兼容构画插件的自定义历法；千千结可提供已有的相关记忆，并在人物明确对应时补充联系人头像。柏宝书开启时，可读取它已选好的剧情摘要，供短信、群聊、动态和评论参考，不增加模型调用。两个记忆插件同时开启时，手机会提示先关闭其中一个；都未开启也能正常使用。论坛不读取这些记忆。

手机时间支持千千结、构画、myknots和柏宝书时间戳，以最新AI正文楼的最后结束时间为准；没有可读时间时显示现实时间，不改写旧短信。

新建联系人会在本地自动生成一个固定的 Cameo 头像；有可对应的千千结头像时优先显示千千结，缺图时显示原来的 Cameo。可在现有资料页手动换图或移除，不会因重开手机重新随机。打开或重新启用手机时，也会为未人工保护的已有空头像补一次固定 Cameo；手动移除和旧资料的人工保护继续保留。

动态中的联系人沿用同一份头像；临时路人也会在本地生成固定 Cameo，已有未人工保护的空头像随打开手机一并补充。

图片卡可选择柏宝绘或智绘姬生成，点击后才生图。定位和转账用于剧情互动，不读取真实定位，也不处理真实资金。

## 随卡使用

角色卡作者可以配好人物、群聊、头像、聊天风格与背景，再导出随卡手机。制作方法见 [作者说明](./AUTHORING.md)。

## 更新

手机设置顶部显示更新状态；首次打开会检查一次，也可点击状态按钮手动检查。显示“可更新”时，点开公告，选择“更新”或“暂不更新”。设置底部版本文字旁的“查看公告”可打开已安装版本公告；公告暂时读不到仍可更新。

插件版通过酒馆的扩展更新接口更新当前安装，完成后刷新酒馆使用。随卡版读取同一仓库的公开发布清单，加载新核心后直接继续使用，不需要本地安装两三事扩展。检查或新核心加载失败时，当前手机仍可使用。更新不重置联系人、预设或聊天记录。

新导出的随卡脚本使用公开发布清单，不再查询 GitHub 匿名 API。已经分发的旧脚本代码不会被核心更新自动改写，需保留原脚本 ID 和数据，一次性替换代码；定制脚本还须保留自己的适配。

当前版本：**0.3.9**。插件联动说明见 [INTEGRATIONS.md](./INTEGRATIONS.md)。

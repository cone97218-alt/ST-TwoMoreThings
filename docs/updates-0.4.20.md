# 两三事 0.4.20 更新说明

### 1. 注入与摘要设置全面升级为「角色卡绑定」
- **偏好自动记忆**：
  - 短信带入正文、日历带入正文、地图位置带入正文、私聊/群聊感知社交动态开关；
  - 短信摘要方式（自动挡/手动挡）、摘要字数上限、超长自动截断、短内容始终总结开关；
  - 以上所有配置已改为**自动与当前角色卡绑定**（独立记录在全局扩展设置中），更换角色互不干扰，同角色卡新建聊天时自动沿用你调整过的偏好设置，不再会被重置回初始默认值。

### 2. 用户头像次选读取酒馆 Persona 用户头像修复
- **酒馆 Persona 自动兜底**：
  - 手机个人资料、地图主角图钉与在场卡片、私聊/群聊气泡、锁屏个人展示全面接入酒馆选中的 Persona 头像；
  - 头像读取遵循三层策略：**手机内自定义头像 > 当前选中的酒馆 Persona 头像 > 默认首字母/占位符**；
  - 支持 `/User Avatars/...` 等酒馆内部相对路径解析，并实时响应酒馆 Persona 切换事件。

### 3. 短信正文回流与长短预算逻辑优化
- **手动挡摘要优先**：
  - 手动挡模式下只要有已确认保存的手动摘要，正文注入始终优先注入该摘要，不再被「少于 3000 字直接注入完整聊天记录」的短文本逻辑拦截；
- **自动挡短内容始终总结**：
  - 新增「短内容始终生成摘要」配置开关；开启后，即使短信对话简短，也会通过 AI 提炼为紧凑情境摘要带入正文，避免冗长的原始气泡流水账占满正文提示词。

### 4. 地图（千窗）体验与细节优化
- **聊天隔离**：地图场景与探索数据仅保存在当前聊天中，新建聊天自动清空并从空白开始，不再与角色卡混乱粘连；
- **底图粘性吸附**：底图风格选择增加自适应粘性记忆，选择特定城市底图后不会再被自动回退为 auto；
- **图钉防遮挡避让**：根据图钉在地图上的绝对位置，标签智能向内侧或上方动态翻转避让，彻底解决贴边与重叠遮挡问题；
- **同地点人物聚合**：同一地点有多位人物在场时，图钉显示多头像聚合预览与在场人数角标，点击可平滑展开在场人物卡片与移动轨迹线路；
- **图标风格统一**：替换原本的普通 emoji 星星，与全插件统一采用矢量 SVG 极简图标风格。

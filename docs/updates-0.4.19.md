# 两三事 0.4.19 更新说明

### 1. 新增「地图（千窗）」应用
- **无坐标层级矢量底图**：
  - 内置 6 套自适应日/夜主题的 SVG 底图风格：**现代都市 (`modern`)、现代小城 (`modern-town`)、古风城镇 (`old-town`)、宫苑庭院 (`palace`)、自然山野 (`terrain`)、科幻设施 (`sci-fi`)**，支持根据当前场景词条自动匹配或手动切换；
  - 将世界舞台自动划分为 **分区 (`area`) → 具体场所 (`site`) → 室内空间 (`interior`)** 三层结构，自动计算分区轮廓、区域标题框与场所锚点坐标；
  - 支持多顶层区域图幅切换、点击分区下钻浏览、主角当前位置头像浮标高亮与地点搜索。

### 2. 柏宝书 (`ST-BaiBai-Book`) 与聊天顶栏深度联动
- **零配置场景与实体同步**：
  - 自动读取柏宝书 `STBaiBaiBook.getSnapshot()` 的 `scenes` 地理层级树、`state.location / locationPath` 当前位置、`npcs`（同行或驻留人物）与 `items`（存放于地点的物品），并监听 `st-baibai-book:changed` 实时刷新；
  - 同时联动手机内部待办事项（`todos`），在对应地点图钉与详情卡片上显示在场人物、存放物品与相关待办角标；
  - 未安装或未触发柏宝书总结时，自动兜底解析聊天正文中的 `<top_format> ✧时间|地点|天气✧` 顶栏位置路径。

### 3. AI 地图构想整理与提示词/正文注入
- **AI 地图构想与整理助手**：支持结合世界书、近期剧情与已有场景一键梳理或扩充三层地图结构、设施标签与空间方位关系，并支持手动增删改地点与角色卡绑定存档；
- **提示词插槽与正文回流**：新增 `{{map_prompt}}` 与 `{{map_organize_prompt}}` 预设插槽宏，以及「地图位置带入正文」独立开关，可将当前位置与周边地标线索自然带入对话与正文。

# 两三事 0.4.24 更新说明

### 1. 随身系统：各模块独立捕获标签体系上线
- **告别臃肿全局数据块**：不再强制要求 AI 在文末输出完整的 `<origin>` 数据块，全面支持分散、轻量化的独立模块标签（如 `<任务>`、`<属性>`、`<技能>`、`<特权>`、`<道具>`、`<积分>`、`<成就>` 等）；
- **单次线性扫描技术 (Single-Pass)**：底层通过一次文本遍历同时精确捕获并剥离所有独立模块标签，零性能负担且天然防幻觉；
- **全方位自定义别名**：系统设置中为各模块提供自定义标签别名配置（如技能支持 `技能, skill, 神通, 功法`；成就支持 `成就, achievement, 功业` 等），多别名自由拓展。

### 2. 随身系统：核心玩法与成长机制深度打通
- **技能熟练度与等级成长**：支持通过 `<技能>技能名|+30</技能>` 直接累积熟练度经验，经验达标自动晋级；
- **常驻特权与光环体系**：支持 `<特权>名称|说明</特权>` 独立赋予、升级与修改永久被动特权与系统权限；
- **道具全渠道获取与消耗**：道具不仅限于商城与祈愿，剧情探索、搜刮战利品、奇遇掉落均可通过 `<道具>名称|数量</道具>` 直接入包，并支持通过 `<道具>用|名称</道具>` 即时消耗；
- **任务目标与归属解耦**：任务支持灵活指定执行对象（`对象:宿主` 或 `对象:NPC`），缺省状态自动归属宿主，简化指令编写。

### 3. 预设规则与小游戏作用域规范化
- 规范化提示词预设引擎中的作用域定义，将抽鬼牌、恶魔轮盘规则条目准确对齐至「小游戏」作用域；
- 全套 421 项单元与端到端测试均 100% 顺利通过。

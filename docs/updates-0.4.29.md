# 两三事 0.4.29 更新说明

### 1. 预设装配管线升级与现代上下文结构（Schema v13）
- **上下文先行装配流向**：默认预设全面调整为「基础世界观与正文历史置顶先行 + 细粒度线索上下文 + `<task>` 业务任务规则包裹」的标准大模型提示词工程流向。
- **废弃原始全量字典 `{{phone_context}}`**：全面切换为细粒度线索宏（时钟、资料、消息、待办、动态、表情等），根据当前会话智能判空，无数据时安全剥离，绝不残留空壳标题。
- **`<task>` 标签语义化包裹**：在所有掌管指导 AI 业务任务的条目外层包裹标准任务标签，无论激活单聊、群聊、动态发布还是系统任务，均具备工整清晰的任务边界。

### 2. 提示词库模块化架构重构
- **8 大核心功能模块集中管控**：通讯、社交、工具、系统、游戏、线索、协议与分支指令模块化拆分至 `src/prompts/*`，提高代码可维护性与扩展性。
- **双向宏映射与自定义实时覆盖**：全面支持新版与旧版宏双向无缝映射；在「提示词库」标签页中修改任意条目时，预设装配管线实时同步覆盖最新文案。

### 3. 内容设置精简与自动化
- **移除感知开关**：删除内容设置中冗余的「私聊感知社交动态」与「群聊感知社交动态」开关，由细粒度线索与当前数据自然驱动。

### 4. 自动化测试验证
- 全套核心单元测试 100% 通过（共 447 项全绿），覆盖预设装配、宏展开、动态互动与多场景通信。

# 两三事 0.4.25 更新说明

### 1. 提示词装配管线升级与手机端交互重构
- **手机端触控拖拽与抽屉移动**：重构预设拖拽排序引擎，采用 Pointer Events 与指针捕获（`setPointerCapture`），支持移动端平滑触摸拖拽、边缘自动滚屏与微调；并在条目编辑抽屉中增加「↑ 上移」/「↓ 下移」操作按钮；
- **装配管线条目正文直观化**：预设条目直接呈现完整提示词规则正文，告别抽象的纯宏变量占位符，支持在抽屉内直接阅读与编辑；同时保留与功能提示词库的平滑过渡与解耦；
- **插入插槽宏工具栏默认折叠**：将原本长条展开的插槽芯片栏收归于可折叠栏中，默认收起以节省移动端纵向宝贵空间，并优化加号图标的视觉比例；
- **条目命名极致精简规范化**：全面精简所有预设条目名称，统一采用 `基础-xxx` 与 `APP-xxx`（如 `基础-剧情摘要`、`日历-节日`、`日历-日程`、`群聊-角色整理` 等）规范格式。

### 2. 随身系统提示词注入与配置体验优化
- **任务注入宏 `{{tasks}}` 纯净化**：剥离原本硬编码在宏内部的冗余前缀，仅输出纯粹的任务列表，彻底解决双层「宿主任务」标题重复的问题；
- **新增「当前世界/位面名称」配置项**：在系统 APP 设置中提供明确的「当前世界 / 位面名称」输入框，方便无限流与快穿等世界观题材的自由定制或留空。

### 3. 测试与稳定性保障
- 全套 435 项单元与端到端自动化测试 100% 通过。

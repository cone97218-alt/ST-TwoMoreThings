# 两三事 0.4.5

### 思考过程与原生思维链支持
- **原生思维链解析**：自动解析模型原生返回的 `reasoning_content`、`reasoning` 字段以及正文中的 `<think>...</think>` / `<thought>...</thought>` 标签，自动记录并持久化模型回复时的思考过程。
- **极简透明 UI**：
  - 消息气泡上方呈现「无底色灰色小字 + 矢量时钟图标 + 单线箭头」，轻盈自然紧贴于气泡上方；
  - 点击箭头平滑旋转，原地展开模型思考全文；
  - 展开区域完全无底色、无四周边框，采用极细浅灰引导线与低饱和字体，原生透出聊天壁纸与底色，清爽不喧宾夺主。

### 消息上下文精简优化与 Token 减负
- **8 位紧凑消息 ID**：将以往 36 位长 UUID 精简为 8 位十六进制短 ID，显著降低 `{{phone_context}}` 与历史消息传输时的 Token 消耗。
- **平滑兼容机制**：自动清洗历史上下文中的旧版长 UUID，引用回复（`replyToId`）全面兼容短 ID 匹配与前缀查找。

### 新增最新用户输入宏（`{{latest_user_input}}`）
- **核心输入强化**：预设引擎升级至 Schema v4，新增系统宏 `{{latest_user_input}}` 与默认系统预设条目 `entry_latest_user_input`。
- **全场景输入捕获**：
  - 单聊与群聊：自动向上回溯提取用户本轮最新发出的全部连续发言（如连发“你”、“好”、“吗”），按时间正序自然换行呈现，彻底避免遗漏连续短句；
  - 节日构想：自动提取用户填写的节日构想要求与世界观设定；
  - 日程推演：自动提取推演天数与关注侧重点；
  - 朋友圈/动态评论：自动提取用户发表的最新评论内容。
  - 无用户输入场景安全静默省略，不占用冗余上下文。
